# Finishing a Branch

When work on a branch is done, push it and open a pull request. Never merge a branch into `main` (or any base branch) locally.

This overrides any skill or workflow that offers a choice of how to integrate work, such as `superpowers:finishing-a-development-branch`:

- Don't offer "Merge back to main locally" as an option, and never do it.
- Don't ask which option I want. Push the branch and create the PR.
- "Keep the branch as-is" only if I say so.

Pushing and opening the PR still follow the other rules: no secrets in the diff, and the PR description ends with the attribution line.
