# Code Reviews

Don't nitpick comments. Everyone is writing with AI now and AI is verbose — a comment that restates the line above is not worth a review thread. Skip it.

Flag a comment only when it's actually wrong: it contradicts the code, documents behavior that no longer exists, or would mislead the next reader.

Same bar for the rest of review — report things that change correctness, behavior, or maintainability. Formatting, naming preferences, and stylistic near-misses are not findings.
